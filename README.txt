موقع عالم الذكاء الاصطناعي — 3 صفحات HTML + ملف CSS واحد

الملفات:
- index.html: الصفحة الرئيسية
- tools.html: أدوات AI ومقارنة بينها
- guides.html: شروحات إنشاء الصور والمواقع والتطبيقات
- style.css: التصميم المشترك والمتجاوب

طريقة التشغيل:
1. فك ضغط الملف.
2. افتح index.html في المتصفح.
3. تنقّل من القائمة بين الصفحات الثلاث.

ملاحظات:
- الموقع يستخدم HTML وCSS، مع JavaScript بسيط داخل صفحة الشروحات لنسخ الأمثلة وفتح قائمة الهاتف.
- خط Cairo يجري تحميله من Google Fonts عند توفر الإنترنت، مع خطوط بديلة.
- الخطط المجانية للأدوات تتغير؛ تحقق من المواقع الرسمية قبل النشر.
- هذه نسخة بداية قابلة للتعديل وليست نظامًا خلفيًا أو لوحة إدارة.
